## A. GitHub Release notes — v1.0.0

### DbDelta 1.0.0 — first stable release

DbDelta is an open-source schema comparison and deployment tool for Microsoft
SQL Server — an OSS alternative to Redgate SQL Compare. This is the first
stable release after <<N>> release candidates.

**Install:** download `DbDelta-1.0.0-win-x64.msi` below. It installs the
desktop app (Start-Menu shortcut) and the `dbdelta` CLI (added to `PATH`).
The MSI is signed. Upgrading from an RC: uninstall the RC first (RCs shared
the 1.0.0 ProductVersion).

**What you get**

- **Compare** the schema of two live SQL Server databases (2016+ / Azure SQL
  DB) across 13 object kinds: tables (columns, constraints, indexes), views,
  stored procedures, functions, triggers, sequences, synonyms, user-defined
  types, table types, users, roles, permissions.
- **Generate** a dependency-ordered, self-contained T-SQL alignment script —
  Redgate-style verbose envelope: `SET` preamble, single transaction, a
  `PRINT` + error gate per step, succeeded/failed verdict with rollback.
  Runs identically from `dbdelta apply`, `sqlcmd`, or SSMS.
- **Deploy** transactionally from the GUI or the CLI (`dbdelta apply`,
  `--dry-run` supported).
- **Report** in self-contained HTML and machine-readable JSON.
- **Desktop GUI** (Avalonia 11): connection manager with DPAPI credential
  store, `.dbd` projects, side-by-side DDL diff with hints, script preview,
  transactional apply, version pill linking the running build to its
  [version history](https://gitbakko.github.io/db-delta/articles/version-history.html).
- **Calibrated against Redgate SQL Compare 16** on a live 17-scenario parity
  fixture — audits in [`docs/parity/`](https://github.com/GitBakko/db-delta/tree/main/docs/parity).

**Docs:** <https://gitbakko.github.io/db-delta/> ·
**Full changelog:** <https://gitbakko.github.io/db-delta/articles/version-history.html>

Known v1 limits: Live DB ↔ Live DB only (no scripts-folder/snapshot sources
yet), Windows-first. See the roadmap discussion in the repo.
