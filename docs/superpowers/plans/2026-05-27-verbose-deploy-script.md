# Self-contained Verbose Deploy Script Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make DbDelta's default deploy script self-contained and Redgate-style — a SET preamble + transaction, a `PRINT` phase label before every operation, an `IF @@ERROR <> 0 SET NOEXEC ON` gate after every batch so the deploy aborts at the first failure, and a final succeeded/failed verdict that rolls back on failure — and adapt the `apply` path so the script governs its own transaction.

**Architecture:** A new pure `DeploymentScriptWriter` owns batch framing (`PRINT`/`GO`/body/`GO`/gate/`GO`) + the preamble + the verdict footer. `ScriptGenerator` routes every emit site through it with a computed phase label; the per-object emitters are unchanged. `SqlExecutor` gains a `useOwnTransaction` flag (default `true`); callers that apply a DbDelta-generated (self-managing) script pass `false`.

**Tech Stack:** C# / .NET 10; xunit.v3 + FluentAssertions; Verify.Xunit (goldens); Testcontainers.MsSql (live error-path tests); `Microsoft.Data.SqlClient`.

## Redgate verdict-block mechanism (why it works)

When a batch errors, its gate sets `NOEXEC ON` → every later batch is compiled-but-not-executed. In the final verdict batch, `DECLARE @Success` still *compiles* (so the variable exists) but `SET @Success = 1` is skipped → `@Success` is `NULL`; `SET NOEXEC OFF` re-enables execution; `IF (@Success = 1)` is then false (NULL) → the `ELSE` branch rolls back and prints "failed". On a clean run, NOEXEC stays off, `@Success = 1`, `COMMIT` ran, and it prints "succeeded". `SET XACT_ABORT ON` is the real rollback safety (it dooms the transaction on any runtime error); the gate stops later batches. **The live failing-step test (Task 5) is the gate that proves this actually aborts + rolls back.**

    string connectionString,
    string script,
    CancellationToken ct,
    bool useOwnTransaction = true)

    var sw = Stopwatch.StartNew();
    try
    {
        await using SqlConnection cn = new(builder.ConnectionString);
        await cn.OpenAsync(ct).ConfigureAwait(false);

        SqlTransaction? tx = useOwnTransaction
            ? (SqlTransaction)await cn.BeginTransactionAsync(ct).ConfigureAwait(false)

            {
                await using SqlCommand cmd = tx is null
                    ? new(batch, cn) { CommandTimeout = CommandTimeoutSeconds }
                    : new(batch, cn, tx) { CommandTimeout = CommandTimeoutSeconds };
                await cmd.ExecuteNonQueryAsync(ct).ConfigureAwait(false);
                executed++;
            }
            if (tx is not null) { await tx.CommitAsync(ct).ConfigureAwait(false); }
            sw.Stop();
            return new SqlBatchResult(true, null, executed, (int)sw.ElapsedMilliseconds);
        }
        catch (Exception ex)
        {
            if (tx is not null)
            {
                try { await tx.RollbackAsync(ct).ConfigureAwait(false); } catch { /* best-effort */ }
            }
            sw.Stop();
            return new SqlBatchResult(false, ConnectionStringRedactor.Redact(ex.Message), executed, (int)sw.ElapsedMilliseconds);
        }
        finally
        {
            if (tx is not null) { await tx.DisposeAsync().ConfigureAwait(false); }
        }
    }
    catch (Exception ex)
    {
        sw.Stop();
        return new SqlBatchResult(false, ConnectionStringRedactor.Redact(ex.Message), 0, (int)sw.ElapsedMilliseconds);
    }
}

```csharp
using System.Text;

namespace DbDelta.Core.ScriptGen;

/// <summary>
/// Emits a self-contained, Redgate-style deployment script: a SET preamble +
/// BEGIN TRANSACTION, each operation wrapped as a PRINT phase label + body + an
/// `IF @@ERROR &lt;&gt; 0 SET NOEXEC ON` gate, and a final succeeded/failed
/// verdict that rolls back on failure. With <paramref name="useTransaction"/>
/// false the BEGIN/COMMIT are omitted (the verdict still rolls back any open
/// transaction).
/// </summary>
internal sealed class DeploymentScriptWriter(StringBuilder sb, bool useTransaction)
{
    public void WritePreamble(bool includeHeader)
    {
        if (includeHeader) { sb.AppendLine("-- Generated by DbDelta"); }
        Batch("SET NUMERIC_ROUNDABORT OFF");
        Batch("SET ANSI_PADDING, ANSI_WARNINGS, CONCAT_NULL_YIELDS_NULL, ARITHABORT, QUOTED_IDENTIFIER, ANSI_NULLS ON");
        Batch("SET XACT_ABORT ON");
        Batch("SET TRANSACTION ISOLATION LEVEL SERIALIZABLE");
        if (useTransaction)
        {
            Batch("BEGIN TRANSACTION");
            Batch("IF @@ERROR <> 0 SET NOEXEC ON");
        }
    }

    public void WriteBatch(string label, string body)
    {
        if (string.IsNullOrWhiteSpace(body)) { return; }
        sb.Append("PRINT N'").Append(label.Replace("'", "''", StringComparison.Ordinal)).AppendLine("';");
        sb.AppendLine("GO");
        sb.AppendLine(body.TrimEnd());
        sb.AppendLine("GO");
        sb.AppendLine("IF @@ERROR <> 0 SET NOEXEC ON;");
        sb.AppendLine("GO");
    }

    public void WriteVerdict()
    {
        if (useTransaction)
        {
            Batch("COMMIT TRANSACTION");
            Batch("IF @@ERROR <> 0 SET NOEXEC ON");
        }
        // DECLARE compiles even under NOEXEC (variable exists); SET is skipped on
        // error, leaving @Success NULL → the ELSE branch rolls back + reports failure.
        sb.AppendLine("DECLARE @Success AS BIT");
        sb.AppendLine("SET @Success = 1");
        sb.AppendLine("SET NOEXEC OFF");
        sb.AppendLine("IF (@Success = 1) PRINT 'The database update succeeded'");
        sb.AppendLine("ELSE BEGIN");
        sb.AppendLine("    IF @@TRANCOUNT > 0 ROLLBACK TRANSACTION");
        sb.AppendLine("    PRINT 'The database update failed'");
        sb.AppendLine("END");
        sb.AppendLine("GO");
    }

    private void Batch(string statement)
    {
        sb.AppendLine(statement);
        sb.AppendLine("GO");
    }
}
```

```csharp
private static string PhaseLabel(DifferencePair pair)
{
    ObjectIdentity id = pair.Identity;
    bool schemaScoped = id.Kind is not ("User" or "Role" or "Permission");
    string name = schemaScoped ? $"[{id.SchemaName}].[{id.ObjectName}]" : $"[{id.ObjectName}]";
    string verb = pair.Status switch
    {
        DifferenceStatus.OnlyInA => "Creating",
        DifferenceStatus.OnlyInB => "Dropping",
        DifferenceStatus.Different => "Altering",
        _ => "Processing",
    };
    return $"{verb} {id.Kind} {name}";
}
```

        await c.OpenAsync(ct);

        object? r = await cmd.ExecuteScalarAsync(ct);
        return r is not null && r != DBNull.Value;
